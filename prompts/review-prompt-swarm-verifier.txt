A candidate is confirmed only when all three of these hold, and you say which one failed when you reject it:

2. Reachability. There is a concrete input, state or sequence under which the mechanism actually runs and produces the wrong outcome. Follow the callers, the invariants the surrounding code establishes (ordering, what is persisted before what, which states can coexist) and the precision of the values involved.
